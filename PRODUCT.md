## Platform

## Users

Prospective employers, recruiters, and fellow engineers evaluating Barun Tayenjam's profile, experience, and open-source tools.

## Product Purpose

A personal website portfolio for Barun Tayenjam that showcases his experience as a Technical Lead, his open-source development tools, and his commitment to secure, high-performance web platforms and AI-enhanced developer workflows.

## Positioning

A technical lead portfolio emphasizing 15+ years of experience in secure web platforms, automation (CI/CD, SearchUnify-scale), and AI-driven development.

## Operating Context

A static website hosted on GitHub Pages, with interactive visual elements (`canvas-container`), content managed via `content.json`, and commit data from `commits.json`.

## Capabilities and Constraints

- Displays personal profile, experience, education, skills, and testimonials.
- Features an interactive "commit galaxy" for portfolio navigation.
- Links to open-source tools and social profiles.
- Accessible via modern browsers; requires JavaScript.
